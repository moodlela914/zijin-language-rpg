# 匯出與匯入學習歷程

遊戲上方提供「匯入學習歷程」，所有階段均可使用。匯入在瀏覽器本機讀取檔案，不會上傳至伺服器。

1. 按「匯入學習歷程」，選擇遊戲匯出的 JSON（最多2 MB）。
2. 預覽已完成關卡、作答筆數、文墨及還原方式。
3. 按「確認匯入並取代目前旅程」才寫入。取消、壞檔或不支援版本都不會取代目前進度。
4. 匯入前會自動備份原旅程。再次開啟本視窗，選「預覽上次匯入前的備份」可查看並還原。

新版 JSON 保留原學習摘要欄位，另含 `format: zijin-language-rpg-history`、`formatVersion: 1` 與完整遊戲狀態，可恢復作答、訂正、關卡、氣血、道具與目前階段。題中倒數以剩餘時間暫停保存，匯入後按「繼續試煉」恢復。

舊版 JSON 摘要也能匯入：保留作答、訂正、文墨與可核對的已完成關卡，從皇城圖繼續。舊檔沒有保存的氣血、道具及題中狀態重新準備，不會假裝能完整還原。音量偏好與貼紙人物的位置屬裝置設定，不隨學習歷程移轉。

若其他分頁在匯入預覽期間更新進度，確認時會拒絕覆蓋；取消視窗會讀回最新旅程。儲存失敗時保留原旅程及既有備份。

驗證包含新版完整狀態及剩餘時間往返、舊摘要續玩、無效檔案、儲存失敗、備份保留及跨分頁衝突。
