# 執行圖片與載入策略

原始97張 PNG 保留不改；`scripts/optimize-assets.py` 產生 WebP 桌面與手機兩套副本。執行索引是 `public/assets/optimized/catalog.json`，原圖製作索引仍為 `public/assets/catalog.json`。

| 圖片集合 | 大小 | 相對原圖減少 |
| --- | ---: | ---: |
| 原始97張 | 167,073,973 bytes | — |
| 桌面97張 | 9,830,852 bytes | 94.1% |
| 手機97張 | 3,582,500 bytes | 97.9% |

桌面背景長邊1280px、人物800px；手機背景768px、人物448px，保持比例及透明度。圖框桌面1200px、手機768px。<=720px 初次進入時使用手機索引；調整視窗後重新整理可切換版本。

全新地圖旅程優先準備6張必要圖，桌面合計789,266 bytes、手機303,326 bytes；恢復關卡時改載目前背景與人物。開場畫面顯示實際已完成圖片數與百分比。載入最多3張並行，每張8秒逾時，失敗不阻止進入；其他圖隨場景需求載入，圖鑑保持 lazy loading。素材索引下載及 JSON 讀取也有8秒期限；失敗會嘗試備援索引，仍失敗則顯示重新載入按鈕。

背景音樂為使用者提供的 MP3，維持原檔，依使用者手勢播放；不以等待整首音樂下載阻擋遊戲。上述數字只計圖片檔案，非整頁流量或真實行動網路延遲的測量。過場亦使用 WebP；GitHub Pages 發布自動為程式與樣式加上內容版本號，避免舊快取混用新素材。

## 版面驗收

桌面題目位於場景右側，平板與手機上下排列。題目字級桌面20px、平板19px、手機18px；使用獨立實色金框及內距，裝飾不覆蓋文字。線索內文桌面18px、手機17px，卡片依可用寬度自動換列。
